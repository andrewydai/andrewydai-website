# Summary
I'm building a personal website for myself. The website  is intended to be a showcase of my projects and experiences, primarily for prospective employers and to give myself some visibility.

# technology stack
- This project is currently a base template for an Astro/React.js project. 
- I intend to deploy it to Cloudflare pages as just a client application to serve with a custom domain
- beyond this, you may feel free to add any packages that might help with styling or UI/UX asks I might have

# specifications
- the website should have a main landing page with a few pictures and a blurb of text describing myself
- scrolling through the landing page. I'd like it to feel collage/pinterest in style, with a very open layout and feel. The collage should contain links to the separate pages on my website but in a natural way that isn't just a bulletin point.
- I don't want a header, instead I want a floating container containing buttons that navigate to separate pages. I want it to feel like a notebook, like a Notion page. I'm basing a fair amount of the inspiration from this website: https://chester.how/
- In the "header" portion I want a link to my github, my linkedin, and a download link for my resume
- For the additional pages, I want 4 pages. First is a page titled "Work", then "Projects", then "Games", then "Hobbies"
- for the Work, Projects, and Games sections I want it to be sort of tile or block based, with some sort of hover state, and have it be expandable but collapsed at the start. I want each to have an image, title, a small blurb, and then a large area for more detailed text on the expanded portion. It should also support being able to add links and images in the expanded portion.
- I want each tile/block to also be able to add badges which show skills or technologies i might have worked with
- For the "Hobbies" section, I want it a little more free formed, like the collage style of the landing page really with just small blurbs and images
- I want the static content to be in a neatly organized section, where i can readily edit it. Static content should include the text/sections in the work, project, and games sections. It should also the downloadable resume and any images/gifs i might use. You can use some basic standins for now for each section
